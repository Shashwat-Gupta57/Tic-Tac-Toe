## About

Two-player tic-tac-toe with a scoreboard that keeps count across ten rounds, plus restart for the board and reset for the whole match.

## What it does

- **Scoreboard** — Ten rounds of wins for X and O.
- **Restart & reset** — A new board, or a whole new match.

## Download & run

1. These apps need **Java 21 or newer**. If you don't have it, install it once with the [JRE Installer](https://github.com/Shashwat-Gupta57/JRE-Installer/releases/latest) — one click, no admin rights. Every app looks for Java in the place it installs to first, then in `JAVA_HOME`.
2. Download **`Tic-Tac-Toe-1.0.0-windows.zip`** from the [latest release](https://github.com/Shashwat-Gupta57/Tic-Tac-Toe/releases/latest).
3. Unzip it anywhere you can write to (Desktop, Documents…) and run **`Tic Tac Toe.exe`**.

The folders next to the exe (images, fonts, saves) are part of the app — keep them together.

## Run from source

Open the folder in **BlueJ** (it's a BlueJ project — `package.bluej`) and run `main.main()`, or with any JDK 21+:

```bash
javac *.java
java main
```
